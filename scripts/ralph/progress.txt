## Codebase Patterns
- Scripts run from `$CONFIG_DIRECTORY/scripts` (set by BlueBuild) — use `${CONFIG_DIRECTORY}/` to reference repo-root files from scripts
- `set dotenv-filename := "xfce-winxp-tc.env"` in justfile loads dotenv from the justfile's directory upward (Just traverses up the tree)
- When justfile uses dotenv-loaded vars in `#!/bin/bash` recipe blocks, use `$VARNAME` (shell env), NOT `{{ VARNAME }}` (Just variable)
- Use `# shellcheck disable=SC1091` for sourced files with dynamic paths; use `# shellcheck disable=SC2046` when intentional word-splitting for package lists
- shellcheck severity: SC1091 is "info" level — `--severity=warning` passes even with this
